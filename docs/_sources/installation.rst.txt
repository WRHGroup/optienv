=============
Installation
=============

Requirements
============

- **Python**: 3.10+ (Linux / macOS / Windows)

Install from PyPI
=================

.. code-block:: bash

   pip install optienv

Install for development
=======================

.. code-block:: bash

   git clone https://github.com/WRHGroup/optienv.git
   cd optienv
   pip install -e .

Smoke tests
===========

.. code-block:: bash

   optienv --help
   optienv search --help
   optienv front --help
   optienv hypervolume --help
